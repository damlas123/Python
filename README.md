# 🐍 Python Learning & Projects Journey

Bu repo; Udemy kursları, veri yapıları çalışmaları ve çeşitli otomasyon/script denemeleri dahil olmak üzere Python programlama dilini öğrenirken ve geliştirirken yazdığım kodları içermektedir.

## 📂 İçerik Yapısı

- **`Udemy_kurs/`**: Python temelleri ve ileri seviye eğitimler sırasında yapılan pratikler ve alıştırmalar.
- **`DATA STRUCTURE/`**: Python ile veri yapıları ve algoritmalar üzerine yapılan çalışmalar.
- **`Scriptler & Uygulamalar/`**: 
  - `fetch_tweets.py`: Twitter/X veri çekme ve otomasyon betiği.
  - Temel algoritmik uygulama dosyaları (`nested.py`, `zig_enumeration.py` vb.).

## 🛠️ Kullanılan Teknolojiler
- **Dil:** Python 3
- **Odak Alanları:** Temel Programlama, Veri Yapıları, Otomasyon Scriptleri
